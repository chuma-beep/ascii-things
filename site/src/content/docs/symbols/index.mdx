A copyable library of printable ASCII, blocks, box-drawing characters, arrows,
shapes, math, and marks. Click any glyph to copy it, filter by family, or start
with one of the density ramps.

<SymbolBrowser />

## Using symbols

These characters are the raw material for `text`, `glyphs`, and `charset`
options across ascii-things. Use a ramp when you want a controlled gradient, or
pick individual glyphs when you need borders, markers, or a specific diagram.

All characters are rendered from the same monospace stack, so the grid stays
aligned wherever the source text is used.
