Every scene is a small artificial-life simulation, not a looped animation. The engine owns
the clock, resize handling, DPR cap, pointer input, off-screen pausing, and reduced-motion
behavior. The scene owns state, rules, and drawing.

## Shared model

| Concept | Behavior |
| --- | --- |
| Seed | Same seed and size produce the same world |
| Palette | Four built-ins or a custom palette object |
| Columns | Art-direction target; cell size adjusts |
| Max cells | Caps the grid at 4K and other large surfaces |
| Speed | Time scale; `0` freezes |
| Calm | Removes flicker and sparkle |
| Interactive | Pointer input, on by default |
| Label | Makes the canvas `role="img"` with a name |
| Events | `onEvent` receives scene-specific moments |

## Defaults

| Scene | `columns` | Population default | Interaction |
| --- | --- | --- | --- |
| Sharks | `124` | Four classic sharks, density `1` | Pointer flee, click splash |
| Robots | `150` | Fleet scales with area | Pointer avoidance, click dispatch |
| Jellyfish | `140` | Bloom scales with area | Pointer current, click shockwave |
| Dog | `150` | One dog, count scales 1–3 | Pointer tracking, click throw |

All scenes share `maxCells: 16000` and `maxDpr: 2`.

## Choosing a scene

- **Sharks** are the busiest and most narrative. Good for a large hero or a section divider.
- **Robots** read as work and systems. Good for product, infrastructure, and developer tools.
- **Jellyfish** are the calmest. Good behind text, in dark sections, and on slow pages.
- **The dog** is the most legible character. Good for a hero with a command input, a playful
  empty state, or a landing page.

All four are ambient. None of them should carry essential information. Read
[Accessibility](/guide/accessibility/) before shipping a scene behind content.
