This playground composes the ten classic scenes. It uses the vanilla engines so the readout can
poll `getStats()` and the scene can be remounted when a structural option changes. Every control
is part of the URL preset, and the generated vanilla, React, and custom-element snippets update
with it.

<Playground client:load />

The [surface playground](/surface-playground/) is the same idea for the shader-backed WebGL
family: choose a variant, density, cell size, speed, glyph ramp, and colours. Use the
[social card studio](/social-card/) to bake any scene into a 1200 × 630 PNG. Scene demos and the
surface composer also capture a three-second looping GIF and a four-second video from the live
canvas. Video capture uses a real H.264 MP4 encoded with WebCodecs when the browser supports it,
then falls back to WebM (or the browser's MP4 MediaRecorder path); the composition tabs expose the
same Copy link / Open in playground pair as the standalone demos.

## What the controls do

| Control | Effect |
| --- | --- |
| Scene tabs | Swaps the engine and remounts the demo |
| Palette tabs | Calls `setOptions({ palette })` on the running engine |
| Glyph style | Remounts with the ASCII or kanji renderer |
| Seed | Remounts with a new world |
| Cell size / columns | Remounts with a new art-direction target |
| Density | Scales the population and remounts |
| Speed | Calls `setOptions({ speed })` live; `0` freezes |
| Pause / Resume | Calls `pause()` / `resume()` |
| Calm | Calls `setOptions({ calm })`; removes flicker and sparkle |
| Pointer | Enables or disables canvas pointer interaction |
| Copy link | Copies the current URL preset |
| Save preset | Stores the configuration in this browser |

The palette, speed, calm, and pointer controls are applied live; seed, columns, density, glyph
style, and scene identity remount the engine.

## Share a preset

The URL stores a compact `p=` parameter. It contains the scene, palette, glyph family, seed, cell
size, density, speed, calm, pause, and pointer state, plus the sampled preset versions used by the
image and surface labs. Open a copied link and the playground restores the configuration before it
starts writing new state.

```text
/playground/?p=eyJ2IjoxLCJraW5kIjoic2NlbmUiLCJzY2VuZSI6ImRvZyIsInBhbGV0dGUiOiJhbWJlciIsInNlZWQiOjd9
/surface-playground/?p=eyJ2IjoxLCJraW5kIjoic3VyZmFjZSIsInZhcmlhbnQiOiJnbG9iZSIsImRlbnNpdHkiOjAuM30
```

The older query keys (`scene`, `palette`, `seed`, `columns`, `speed`, `calm`, `interactive`) are
still accepted when you paste a legacy example URL.

<Aside type="note" title="Reduced motion">
When your OS asks for reduced motion, the island detects it on the client, turns calm on, and
the engine settles to a still frame. The prompt is disabled because pointer actions are also
disabled.
</Aside>

## Reproduce a configuration

The demos on this site use fixed seeds so screenshots stay stable. To reproduce one:

```tsx
<AsciiDog
  palette="abyss"
  seed={7}
  columns={110}
  label="A live ASCII robot dog test yard"
/>
```

The vanilla equivalent:

```ts
import { createDog } from "ascii-things/dog";

const yard = createDog(canvas, {
  palette: "abyss",
  seed: 7,
  columns: 110,
});

yard.setOptions({ calm: true, speed: 0.8 });
```

## Query-string playground

The repository also has a zero-framework playground at `examples/playground/` that reads its
options from the URL:

```text
/examples/playground/?scene=dog&palette=paper&seed=7&count=2
/examples/playground/?scene=jellyfish&palette=neon&jellies=moon:1.15,atolla:1.05
/examples/playground/?scene=starlings&palette=paper&seed=11&count=120
/examples/playground/?scene=fireflies&palette=neon&seed=13&count=90
/examples/playground/?scene=ants&palette=mono&seed=17
/examples/playground/?scene=koi&palette=paper&seed=19
/examples/playground/?scene=city&palette=neon&seed=23
/examples/playground/?scene=servers&palette=abyss&seed=29
/examples/playground/?calm=1&interactive=0
```

It is a Vite page served by the library’s root `npm run dev`, not by this docs site. See
[Examples](/examples/).
