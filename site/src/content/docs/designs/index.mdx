One glyph study built from the same monospace cell: a 3D cube with 54 sticker cells that rocks
between two three-quarter views without leaving the character grid.

<DesignGallery />

## Motion

The cube is a CSS 3D composition. It rocks slowly between two fixed angles, keeping the top,
front, and side faces visible. `prefers-reduced-motion: reduce` holds it at the first
three-quarter view.

## Build

The cube is a local composition: six faces, nine sticker cells each, using CSS 3D transforms and
the same monospace cell. It is not an exported runtime component. It is a reference for what the
grid can hold: a solid object, a visible top face, and a readable silhouette.
