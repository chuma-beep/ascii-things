One glyph study built from the same monospace cell: a 3D cube covered in ASCII fields, with a
kanji at the center of every 3×3 tile. It turns continuously without leaving the character grid.

<DesignGallery />

## Motion

The cube is a CSS 3D composition. It makes a slow, continuous turn through all six faces, keeping
the kanji and the surrounding ASCII field readable as it moves. `prefers-reduced-motion: reduce`
holds it at a three-quarter view.

## Build

The cube is a local composition: six faces, nine 3×3 tiles each, and a kanji at the center of every
tile. The remaining cells are ASCII marks. That makes 54 kanji and 432 ASCII cells across the cube.
It uses CSS 3D transforms and the same monospace cell. It is not an exported runtime component. It
is a reference for what the grid can hold: a solid object, a visible top face, and a readable
silhouette.
