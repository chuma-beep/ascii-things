One glyph study built from the same monospace cell: a 3D cube with 54 kanji stickers that turns
continuously without leaving the character grid.

<DesignGallery />

## Motion

The cube is a CSS 3D composition. It makes a slow, continuous turn through all six faces, keeping
the top, front, and side readable as it moves. `prefers-reduced-motion: reduce` holds it at a
three-quarter view.

## Build

The cube is a local composition: six faces, nine kanji cells each, alternating black and white
sticker sets. It uses CSS 3D transforms and the same monospace cell. It is not an exported runtime
component. It is a reference for what the grid can hold: a solid object, a visible top face, and a
readable silhouette.
