A 3D cube built from six faces, each a 3×3 sticker grid. Every sticker is a preformatted ASCII
field with a kanji at its center, and the six faces alternate between black and white.

<DesignGallery />

## Motion

The cube rocks between two three-quarter views, keeping the top, front, and side visible. It
respects `prefers-reduced-motion` and settles to a still three-quarter view.

## Build

Each face is a CSS 3D plane. The sticker fields are real `<pre>` text, not generated glyph
textures, so the cube is made from the same monospace grid as the rest of the library:

```text
·永·
永永永
·永·
```

The full cube uses 54 of these fields: nine per face, with a different kanji at each center.
The palette is strictly black and white.
