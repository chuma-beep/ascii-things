One glyph study built from the same monospace cell: a raymarched object that turns in
perspective without leaving the character grid.

<DesignGallery />

## Motion

The Rubik's cube is a `rubik-3d` WebGL variant. Its top layer completes a slow quarter turn,
pauses, and resets into the solved grid. It respects `prefers-reduced-motion` and settles to a
still frame.

## Use the cube

```tsx
import { AsciiSurface } from "ascii-things/webgl/react";

<AsciiSurface
  variant="rubik-3d"
  text=""
  density={0.3}
  cell={7}
  foreground="#e8d5a8"
  accent="#ff7a1a"
  style={{ height: 380 }}
/>;
```

The cube is a local composition rather than an exported runtime component. It is a reference for
what the grid can hold: a solid object, a moving layer, and a readable silhouette.
