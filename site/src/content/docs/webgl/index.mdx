`ascii-things/webgl` is no longer one surface. The same engine now ships twelve
glyph-rendered scenes: a rotating globe, water rings, a flow field, a tunnel,
falling code, a woven torus, terrain, a galaxy, voronoi cells, plasma, caustics,
and a constellation. Each runs on the GPU, falls back to a 2D glyph field, and
respects reduced motion and page visibility.

<WebglGallery to={6} />

## Use one

Every variant is the same component with a different `variant`:

```tsx
import { AsciiSurface } from "ascii-things/webgl/react";

export function Globe() {
  return <AsciiSurface variant="globe" text="" style={{ height: 360 }} />;
}
```

The custom element uses the same name as an attribute:

```html
<ascii-surface variant="ripple" text=""></ascii-surface>
```
