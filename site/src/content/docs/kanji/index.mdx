Kanji are already glyphs. The same `AsciiSurface` engine can use them as its
character ramp, turning a field into a type study and turning the true 3D
objects into kanji-built models. The lab now collects eight studies: a
wordmark field, a torus, a cube, a helix, rain, a pond, a gate, and a galaxy.

Browse the full set in the [Library](/library/?type=kanji).

## Use one

Pass a short kanji set as `glyphs` and a serif CJK family as `fontFamily`:

```tsx
import { AsciiSurface } from "ascii-things/webgl/react";

export function KanjiTorus() {
  return (
    <AsciiSurface
      variant="torus-3d"
      glyphs="永遠風水火"
      fontFamily="'Noto Serif CJK JP', 'Yu Mincho', serif"
      style={{ height: 320 }}
    />
  );
}
```

The custom element takes the same values as attributes:

```html
<ascii-surface
  variant="torus-3d"
  glyphs="永遠風水火"
  font-family="'Noto Serif CJK JP', 'Yu Mincho', serif"
></ascii-surface>
```

## Glyph sets

- `永龍風水火土空海月花鳥` — the kanji field
- `永遠風水火` — the torus
- `空海山月` — the cube
- `龍神光` — the helix
- `雨風水音` — the rain
- `水波月影` — the pond
- `門光道` — the gate
- `星月夜光` — the galaxy

Keep sets short. Sixteen glyphs is the engine limit, and fewer glyphs read
better at small cell sizes.
